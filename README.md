# عيادة د. محمد صبرة النجار لطب وجراحة الفم والأسنان وتقويم الأسنان
## منصة الويب المتكاملة + نظام الحجز الذكي + إدارة العيادة والمزامنة مع Google Sheets

تطبيق ويب شامل ومتطور مصمم خصيصًا لعيادة **د. محمد صبرة النجار** (أخصائي طب وجراحة الفم والأسنان — تخصص تقويم الأسنان) في ديرب نجم، محافظة الشرقية.

---

## 1. محاور النظام الأربعة الرئيسية

1. **الموقع التعريفي الفاخر (Landing Page):**
   - هوية بصرية ملكية بنفسجية فاخرة (`#6F4785`، `#4E2E63`، `#2E1B3A`، `#FAF7F2`، `#E8D7A1`) متناسقة مع شعار العيادة وصورة الطبيب المعتمدة.
   - استعراض خدمات تقويم الأسنان، زراعة الأسنان، تجميل وتبييض الأسنان، علاج الجذور، حشوات الكومبوزيت، تنظيف الأسنان، والتركيبات.
   - بطاقة فرع ديرب نجم المعتمدة مع الاتصال المباشر ورابط خرائط Google Maps المبني على Plus Code (`PFX6+HRH, Dairab Negm, Diyarb Negm, Al-Sharqia Governorate 7206330`).
   - دليل خطوات الحجز والأسئلة الشائعة وروابط الفيسبوك الرسمية.

2. **نظام الحجز الإلكتروني الذكي (`/booking`):**
   - معالج حجز متعدد الخطوات باللغة العربية (RTL).
   - **قواعد زمنية صارمة محكومة من السيرفر بتوقيت القاهرة (`Africa/Cairo`):**
     - منع حجز مواعيد لنفس اليوم نهائيًا.
     - نافذة الحجز متاحة بدقة للأيام الأربعة التقويمية القادمة فقط.
     - فحص فوري وسعة الفترات لمنع أي حجز مكرر أو متزامن.
   - تأكيد إيداع العربون (150 ج.م) عبر InstaPay برقم هاتف العيادة (`01093591193`).
   - دعم **كود إعادة الزيارة (Re-visit Code)** للإعفاء الكامل من العربون أو الخصم لمرضى المتابعة.
   - توليد رقم مرجعي فريد لكل حجز (مثل `SBR-2610-8492`) مع إمكانية طباعة إيصال الحجز الفوري أو المتابعة عبر واتساب.

3. **لوحة تحكم السكرتارية (`/secretary`):**
   - مؤشرات تشغيلية لحجوزات اليوم والطلبات الجديدة في انتظار التحقق.
   - جدول تفاعلي للبحث والتصفية حسب اليوم أو الحالة.
   - نافذة مراجعة تحويل InstaPay: اعتماد الحجز أو رفضه مع تسجيل سبب الرفض وهوية السكرتارية وتوقيت القرار.
   - إدارة الفترات الزمنية والاستثناءات: إغلاق فترات محددة، إغلاق يوم كامل، إضافة مواعيد استثنائية (تُختم تلقائيًا: `تم إضافته بواسطة السكرتارية`).
   - متابعة مزامنة شيت السكرتارية وتصدير ملف CSV تشغيلي فوري.
   - **حماية RBAC صارمة:** منع السكرتارية من الاطلاع على فواتير المرضى الكاملة أو السجلات المالية للدكتور.

4. **لوحة تحكم الدكتور (`/doctor`):**
   - لوحة قيادية إكلينيكية ومالية: إجمالي المبالغ المطلوبة، المبالغ المحصلة، الأرصدة المستحقة على المرضى، كشوفات اليوم.
   - **السجل الطبي للمرضى (EMR):** ملف كامل لكل مريض يتضمن الزيارات، الخدمات، الفواتير، الأرصدة، والملاحظات الطبية.
   - **نظام الفواتير وسندات القبض:** إصدار فواتير متعددة البنود، حسابات رياضية دقيقة، تسجيل السداد الجزئي أو الكامل، وطباعة فواتير رسمية فاخرة.
   - **إدارة أكواد إعادة الزيارة:** توليد أكواد مشفرة لمرة واحدة لمريض محدد (إعفاء كامل أو رسوم محددة، تحديد مدة الصلاحية، إلغاء الأكواد غير المستخدمة).
   - **مركز تحكم مزامنة Google Sheets API:**
     - إدارة طابور الإرسال (Transactional Outbox).
     - زر مزامنة فورية وإعادة محاولة العمليات الفاشلة.
     - تصدير شيت الدكتور المالي وشيت السكرتارية التشغيلي كملفات CSV.
   - سجل التدقيق الأمني والعمليات (Audit Logs).
   - إعدادات العيادة وتصدير نسخة احتياطية كاملة من قاعدة البيانات (JSON Backup).

## 3. التقنيات المعمارية المستخدمة

- **الواجهة الأمامية:** React 19 + TypeScript + Vite.
- **التنسيق:** Tailwind CSS v4 مع خطوط عربية ملكية (`IBM Plex Sans Arabic` و `Plus Jakarta Sans`) ونمط RTL متكامل.
- **الخادم (Backend):** Node.js Express مع دعم كامل لنموذج المعاملات وخدمة مسارات `/api/*`.
- **قاعدة البيانات:** SQLite مدمجة ومستقرة عبر `node:sqlite` مع قيود علائقية وفهارس وحفظ محلي دائم في `./data/clinic.db`.
- **المزامنة مع Google Sheets:** نمط Transactional Outbox Pattern يضمن تسجيل المعاملات في قاعدة البيانات أولاً ثم معالجتها وإرسالها إلى Google Sheets API مع تتبع الأخطاء والمحاولات.

## 4. خطوات تشغيل المشروع محليًا

1. تثبيت الحزم:
   ```bash
   npm install
   ```

2. تشغيل السيرفر المتكامل (Backend + Frontend):
   ```bash
   npm run dev
   ```
   سيتم تشغيل الخادم على المنفذ `http://localhost:3000`.

3. بناء المشروع للإنتاج:
   ```bash
   npm run build
   npm start
   ```

## 5. إعداد Google Sheets API في بيئة الإنتاج

1. أنشئ مشروعًا جديدًا في [Google Cloud Console](https://console.cloud.google.com/).
2. قم بتفعيل **Google Sheets API**.
3. أنشئ **Service Account** ونزل مفتاح JSON الخاص به.
4. أنشئ ملفي Google Spreadsheet:
   - الأول خاص بالسكرتارية (Secretary Operational Sheet).
   - الثاني خاص بالدكتور (Doctor Financial & Clinical Sheet).
5. شارك كل ملف مع البريد الإلكتروني الخاص بـ Service Account بصلاحية Editor.
6. عيّن المتغيرات في ملف `.env`:
   ```env
   GOOGLE_SHEETS_SPREADSHEET_ID_SECRETARY="معرف_شيت_السكرتارية"
   GOOGLE_SHEETS_SPREADSHEET_ID_DOCTOR="معرف_شيت_الدكتور"
   GOOGLE_SERVICE_ACCOUNT_EMAIL="clinic-sync@..."
   GOOGLE_SERVICE_ACCOUNT_PRIVATE_KEY="-----BEGIN PRIVATE KEY-----..."
   ```
